# Arqam Waheed 👋

Developer from Islamabad, Pakistan 🇵🇰. I started out working through The Odin Project, and these days
I mostly build small AI-powered apps... usually under hackathon time pressure, usually on a free-tier
stack, and usually with GitHub Copilot in the loop.

I like taking a sharp idea and getting it to a working, demoable state quickly. Lately that's meant
multi-agent systems, browser extensions, and a few deliberately strange tools. Right now I'm turning
one of my hackathon projects, Schedio, into a real product.

### Things I've built

- ⚖️ **[Council](https://github.com/ArqamWaheed/council)** — instead of trusting one model, it convenes three. They each take a position, then a judge returns a single verdict with a confidence score and the reasons they disagreed. Python, built on the Hermes Agent runtime. *(Hermes Agent Challenge)*

- 🐾 **[Terra Triage](https://github.com/ArqamWaheed/terra-triage)** — snap a photo of an injured wild animal and a multi-agent system identifies the species, triages the injury, and dispatches a referral to the rehabber most likely to accept, in under a minute. Next.js, Groq vision, Auth0, Supabase. *(DEV Earth Day 2026)*

- 📅 **[Schedio](https://github.com/ArqamWaheed/schedio)** — highlight text on any page and turn it into a Google Calendar event in a few seconds. A Chrome extension built with Plasmo, React, and Gemini. *(GitHub Challenge)*

- 🛡️ **[MergeGuardian 9000](https://github.com/ArqamWaheed/april-fools-hackathon)** — an "enterprise" AI code reviewer with a 0% approval rate that blocks every merge for increasingly absurd reasons. Next.js and Gemini. *(DEV April Fools 2026)*

I'm also working on [Graducate](https://github.com/ArqamWaheed/gradly), a Pakistan-first admissions and tutoring platform.
